# 新版评分初步结果

这里保存新版评分规则（V3）对现有 368 份 Excel 结果的第一次完整重算。

## 结果怎么读

- 322 份算出了数值分数。
- 12 份评分程序暂时读不懂，没有分数。
- 24 份来自有来源和单位问题的旧版政策题，不能继续评分。
- 10 份原生透视表结果还要用 Microsoft Excel 打开并重新计算。

政策情景题的旧版数据来源和单位定义互相冲突，继续评旧答卷会产生误导。修正后的题目还没让三套系统重新运行，所以暂时没有新版分数。

逐题表只使用本轮真正完成、且新版算出分数的 286 份结果。历史额外运行和失败重试不进入平均分。三套系统的数据保留用于核对，不用于当前排名。

原始表中保留了 `replay_pass` 等字段，用于还原当时的 V3 计算。它们使用了尚未校准的 0.70 临时门槛，不参与本轮汇报结论。

图表里的 `n` 是实际进入平均分的结果数。每个“题目 × 系统”原计划运行 8 次。没有产出 Excel、评分程序暂时读不懂、属于旧题版本，或等待 Microsoft Excel 重算的结果不进入平均分，所以各格的 `n` 会介于 5 和 8 之间。

## 当前结论

旧评分规则把大量合理结果写成了低分或 0 分。新版纠正了主体问题，但还没有完成逐题公平性审查。尤其需要继续检查：

- 订单清洗中连续分数与当前关键项判定不一致；
- 原生透视表是否真的连接正确数据并能在 Excel 中刷新；
- C 类文档题的页码、公式、对账和重复表格识别；
- 工程选泵、健康数据和销售数据的不同合理布局；
- 政策情景的新旧题面和结果文件必须彻底分开。

本次只重跑了评分程序，没有让三套系统重新做题。当前清单还没有同时锁定题面、运行配置和结果文件列表，所以这些数据是初步结果。
