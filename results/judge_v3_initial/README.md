# 新版评分初步结果

这里保存新版评分规则（V3）第一次完整重算后、可直接用于当前分析的干净结果表。所有对外表格只保留分数、样本数和复核状态，不包含临时二元判定、成本、账号信息、运行路径或完整内部回放记录。

要审查一道题为什么这样算分，先打开 [Rubric 和 Evaluator 导航](../../docs/EVALUATOR_REVIEW_MAP.md)，再对照该题的题面、`rubric.json` 和 `tests/evaluate.py`。

## 结果怎么读

- 新版规则检查了现有 368 份 Excel 文件，其中 322 份算出了分数。
- 另外 46 份没有分数：12 份评分程序暂时读不懂，24 份属于有来源和单位问题的旧版政策题，10 份还要用 Microsoft Excel 打开并重新计算。这些文件没有被记成 0 分。
- 当前逐题分析只使用本轮真正完成、且新版规则算出分数的 286 份结果。历史额外运行和失败重试不进入平均分。
- 每个“题目 × 系统”原计划运行 8 次。图表中的 `n` 是实际进入平均分的结果数，因此会介于 5 和 8 之间。
- 政策情景题的旧版来源和单位定义互相冲突。修正后的题目还没有重新运行，所以当前没有新版分数。

## 当前结论

旧评分规则把大量合理结果写成了低分或 0 分。新版纠正了主体问题，但还没有完成逐题公平性审查。订单清洗、原生透视表和 5 道 C 类文档题需要继续修改；工程选泵、健康数据和销售数据还要补充不同合理布局；政策情景必须把修正版题面和旧结果彻底分开。

本次只重跑了评分程序，没有让三套系统重新做题。下一轮先固定题面、输入、来源与单位、评分项、评分程序和结果清单，再统一重算。
