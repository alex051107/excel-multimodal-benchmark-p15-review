# 新版评分初步结果

这里保存新版评分规则（V3）对现有 368 份 Excel 结果的第一次完整重算。

## 结果怎么读

- 322 份算出了数值分数。
- 12 份评分程序暂时读不懂，没有分数。
- 24 份来自有来源和单位问题的旧版政策题，不能继续评分。
- 10 份原生透视表结果还要用 Microsoft Excel 打开并重新计算。

逐题表只使用本轮真正完成、且新版算出分数的 286 份结果。历史额外运行和失败重试不进入平均分。三套系统的数据保留用于核对，不用于当前排名。

## 主要文件

| 文件 | 内容 |
|---|---|
| `judge_v3_candidate_task_audit_summary.csv` | 15 道题的新版分数、达标数和异常状态 |
| `judge_v3_candidate_system_audit_summary.csv` | 三套系统的描述性结果；当前不用于排名 |
| `judge_v3_candidate_full_archive_replay.csv` | 368 份 Excel 结果的逐份重算记录 |
| `judge_v3_candidate_full_archive_summary.json` | 本次重算的总数与状态汇总 |
| `old_evaluator_task_results.csv` | 旧评分规则的逐题结果，用于说明为什么要重审 |
| `judge_v3_candidate_fixture_audit.csv` | 168 个标准、等价、错误、空白和损坏测试文件的检查结果 |
| `judge_v3_candidate_manifest.json` | 本次使用的评分文件及校验值 |

## 当前结论

旧评分规则把大量合理结果写成了低分或 0 分。新版纠正了主体问题，但还没有完成逐题公平性审查。尤其需要继续检查：

- 订单清洗中总分与关键要求不一致；
- 原生透视表是否真的连接正确数据并能在 Excel 中刷新；
- C 类文档题的页码、公式、对账和重复表格识别；
- 工程选泵、健康数据和销售数据的不同合理布局；
- 政策情景的新旧题面和结果文件必须彻底分开。

本次只重跑了评分程序，没有让三套系统重新做题。当前清单还没有同时锁定题面、运行配置和结果文件列表，所以这些数据是初步结果。
