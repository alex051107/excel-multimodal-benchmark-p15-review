# Judge V3 Contract

## 题面明确必须结果

- 发票标识、双方、日期、币种和 PO 引用正确。
- 所有行项目只出现一次，数量、单价、所在页及可读溯源信息正确。
- 小计、折扣、税、运费和应付总额正确，行 ID 能连接行项目与溯源表。

## 保留的动态要求

题面明确要求“formula-linked”金额链。行金额与小计、折扣、应税额、税额和应付总额必须由公式连接；修改数量或单价时，整条金额链必须响应。

## V3 删除的非必要惩罚

- 不再要求固定工作表名、固定表名数量或固定单元格地址。
- 按可见标签、表头和业务内容定位数据。
- 折扣可以显示为正数扣减项或负数金额，只要计算语义一致。

## 新正反例

- 正例 `alternate_layout`：任意表名与位置，保留完整动态金额链，应得 1.0/通过。
- 反例 `broken_total`：应付总额公式遗漏运费，必须在 R006/R007 失败。

实际分数与通过状态见 `receipts/judge_v3_local_validation.json`。
