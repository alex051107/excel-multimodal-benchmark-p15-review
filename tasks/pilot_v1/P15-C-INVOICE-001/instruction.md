# Invoice AP Workpaper

Northstar Operations received the attached two-page invoice from Alder & Finch Supply. Complete the supplied starting workbook and save it as `/app/output/answer.xlsx` for the payment reviewer.

Extract the invoice identity and every line item, keeping the document page for each item. Create a formula-linked subtotal, discount, tax, freight, and total payable calculation. Include a compact provenance table that lets a reviewer trace each line back to the supplied document. You may assign any stable unique line IDs, provided the same IDs link the line-item and provenance tables. A locator should name the source file, page, and a human-readable line label; no private token format is required.

Use the document as the source of truth. The workbook must be editable and ready for the next AP review step.
