# Analysis plan

Use Group 2 minus Group 1 for each paired subject. Analyze the paired differences with a two-sided paired t-test, report the 95% t confidence interval, and apply p < 0.05. Do not substitute an independent-groups test.

For planning, use the paired/one-sample normal approximation `ceil(((1.96 + 0.84) / 0.8)^2)`.
