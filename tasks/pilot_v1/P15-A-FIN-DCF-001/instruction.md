# Northstar Components valuation model

The corporate-development team is reviewing a Northstar Components acquisition screen. Build the valuation model in `answer.xlsx` from the historical facts and forecast assumptions provided in this folder.

The decision team needs a five-year unlevered free-cash-flow DCF. Keep the historical facts unchanged, project revenue and operating performance for FY2025E-FY2029E, calculate cash taxes, D&A, capex, and change in working capital, then value the business using the stated WACC and Gordon-growth terminal value. Bridge enterprise value to equity value using the supplied cash and debt assumptions.

Use the existing workbook structure: `Source_Data`, `Assumptions`, `Forecast`, `Valuation`, and `Checks`. The sensitivity block should show equity value for the supplied WACC and terminal-growth combinations. All calculated outputs must remain formula-linked so an associate can change an assumption and see the valuation update.

Deliver `/app/output/answer.xlsx`.
