# Cooling-water pump sizing review

A process engineer has prepared the design inputs and a small approved pump catalog for a cooling-water loop. Complete the sizing workbook and recommend the first eligible pump in the catalog order.

Convert the stated flow and diameter to SI base units. Calculate velocity, velocity head, friction head, total dynamic head, hydraulic power, required shaft power, and the safety-adjusted minimum flow and motor rating. A pump is eligible only when it meets the flow, head, and motor constraints.

Keep units explicit, retain the source inputs, and make the calculations formula-linked so the selection updates when a design input changes. Save the completed workbook to `/app/output/answer.xlsx`.
