# Calculation method

Use SI units. Flow Q is converted from L/s to m³/s and diameter from mm to m. Area = πD²/4; velocity = Q/area; velocity head = v²/(2g); friction head = f(L/D)×velocity head; TDH = (static head + friction head)×(1+safety factor); hydraulic kW = ρgQH/1000; shaft kW = hydraulic kW/efficiency.
