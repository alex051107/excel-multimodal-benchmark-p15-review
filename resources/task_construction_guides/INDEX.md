# Excel Benchmark Builder Skills

These files capture only construction and release practices exercised in P15. They are version-controlled authoring guidance and must never be copied into Agent-visible task inputs.

| Skill | Use when |
|---|---|
| [Task selection](TASK_SELECTION/SKILL.md) | Freezing a diverse PRIMARY portfolio and design-only reserves. |
| [Track A construction](TRACK_A_CONSTRUCTION/SKILL.md) | Building formula/model, debugging, engineering, statistics, or policy tasks. |
| [Track B construction](TRACK_B_CONSTRUCTION/SKILL.md) | Building workspace discovery, joins, reconciliation, native Pivot, or reporting tasks. |
| [Track C construction](TRACK_C_CONSTRUCTION/SKILL.md) | Building document-grounded extraction, provenance, and reconciliation tasks. |
| [Oracle and gold](ORACLE_AND_GOLD/SKILL.md) | Creating independent replay, reference, equivalent, and perturbation assets. |
| [Rubric and Judge](RUBRIC_AND_JUDGE/SKILL.md) | Implementing atomic scoring, failure codes, fixtures, and determinism gates. |
| [Harbor difficulty loop](HARBOR_DIFFICULTY_LOOP/SKILL.md) | Running package smoke, target-Agent attempts, bounded revisions, and pass@k estimates. |
| [Release and scale](RELEASE_AND_SCALE/SKILL.md) | Building review bundles, fixed evidence tables, checksums, and a clean release repository. |

Choose the narrowest applicable skill. A task remains invalid when its required source, native object, independent oracle, or canonical validation cannot be obtained; extra workflow machinery is not a substitute.
